## about Expense Tracker Pro

เว็บแอปพลิเคชันบันทึกและวิเคราะห์ประวัติการใช้เงินส่วนบุคคลแบบง่ายๆ (Manual Entry) ที่ทดลองสร้างด้วย:
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript, Chart.js
- **Database & Cloud:** Firebase Firestore (Realtime DB), Firebase Hosting
- **Features:** 
  - บันทึกการใช้เงินแยกตามธนาคารและหมวดหมู่
  - สรุปสถิติการเงินและแนวโน้มรายวัน
  - ระบบย่อและแนบรูปสลิปการโอนเงิน (Client-side Compression)
